# JavaScript Calculator

A simple and interactive calculator built using **HTML, CSS, and JavaScript**. This project performs basic mathematical calculations through a clean and user-friendly interface.

## Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔄 Clear button to reset calculations
* ⌫ Delete button to remove the last digit
* 📱 Simple and user-friendly interface
* ⚡ Instant calculation results

## Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout
* **JavaScript** – Calculation logic and functionality

## Project Structure

```text
JavaScript-Calculator/
│
├── index.html

```

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Start performing calculations!

##  Project Purpose

The main purpose of this project is to practice JavaScript fundamentals, DOM manipulation, event handling, and basic mathematical operations while developing a practical web application.
